Политика конфиденциальности

Сервис «Склад» — внутренняя учётная система{% if site_owner %}, которую использует {{ site_owner.full_name|default:site_owner.name }}{% endif %}. Здесь описано, какие данные обрабатываются и зачем.

Какие данные обрабатываются

  • Учётные данные сотрудников: логин, имя, роль в системе.
  • Сведения о контрагентах из документов: наименование, ИНН, адрес, телефон, e-mail, банковские реквизиты.
  • Хозяйственные документы: счета, отгрузки, приёмки, платежи, договоры.

Зачем

Только для складского, товарного и бухгалтерского учёта владельца сервиса и для оформления документов по сделкам.

Передача третьим лицам

Данные не продаются и не передаются третьим лицам, кроме случаев, прямо предусмотренных законодательством.

Файлы cookie

Используется один технический файл cookie — он поддерживает сеанс входа сотрудника. Рекламных и отслеживающих cookie на сайте нет.

Хранение и защита

Данные хранятся на сервере, который арендует владелец сервиса. Доступ возможен только после входа по логину и паролю, соединение защищено HTTPS.
